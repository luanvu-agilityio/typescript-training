# TypeScript Practice

## Overview

Welcome to my Student Management Dashboard - a TypeScript-based administrative interface that enables efficient student data management. This project demonstrates the implementation of CRUD (Create, Read, Update, Delete) operations in a user-friendly dashboard environment.

<b>Key Features:<b>

- Complete student lifecycle management
- Advanced sorting and search capabilities
- Intuitive user interface for administrative tasks

The project showcases practical applications of TypeScript while delivering essential functionalities for educational administration. All necessary resources and documentation links are provided below.

## Target

<b>Understanding TypeScript:<b>

- Gain a comprehensive understanding of TypeScript's core features and benefits over JavaScript.

<b>Syntax Mastery:<b>

- Ensure participants grasp TypeScript's syntax, including variables, data types, functions, classes, interfaces, and enums.

<b>Integration:<b>

- Show how TypeScript integrates with libraries and frameworks like React or Angular or any related to TypeScript.

<b>Configuration:<b>

- Equip participants with the skills to configure TypeScript through tsconfig, enabling optimal project setup and customization. Also apply ESLint to find and fix problems in code.

## Step by step to run this app in your locals

| Command                                                                   | Action                           |
| ------------------------------------------------------------------------- | -------------------------------- |
| git clone https://gitlab.asoft-python.com/luan.vu/typescript-training.git | Download the source code         |
| git checkout feat/practice                                                | Checkout to branch feat/practice |
| cd typescript-practice                                                    | Move to folder                   |
| npm install                                                               | Install dependencies             |
| npm run start                                                             | Run the parcel bundler           |
| Alternatively, use live server extension to render images properly        |

<b>Notes:<b>

- Open the browser (with parcel) at: http://localhost:1234
